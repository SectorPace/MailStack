# MailStack v0.5.1-beta.1

Security and integration repair release.

- Correct installer forwarding for admin host and port
- Fixed administrator GitHub link
- Added Webmail health check during installation
- Added login throttling, session expiry, CSRF protection and security headers
- Added safe Maildir path resolution and individual message retrieval
- Added encoded-word header decoding for common UTF-8 subjects
- Added sender identity on local Postfix submission
- Added proxy-aware and secure-cookie options
- Added Nginx reverse-proxy example
- Retained bilingual UI, dark/light themes, local avatar and wallpaper customization
